# Sprint-6
Analisis de anuncios de vehiculos
En esta pagina web se puede explorar los datos de los anuncions de vehiculos usados, a partir de una visualizacion interactiva con los gráficos de dispersion:
El histograma permite visualizar el kilometraje de los vehiculos
El grafico de dispersion permite visualizar la relacion entre el kilometraje y el precio de los vehiculos

la pagina se desarrolló con Streamlit, Pandas y Ploty Express.
